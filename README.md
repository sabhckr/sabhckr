## About

I'm an engineer working across **AI, security and infrastructure**. My day-to-day sits where those meet: using AI to make engineering workflows faster, testing systems the way an attacker would so they can be hardened, and building the networks, pipelines and automation that keep software reliable.

I hold the **Certified Ethical Hacker (CEH)** and **CCNA** certifications, and I do penetration testing and vulnerability research. Outside security work, I build games and simulation tools, because designing large, interactive systems makes me a better systems engineer.

I'm open to collaboration on open-source security tooling, DevSecOps and AI-assisted engineering projects.

**Currently:** building HULKBUSTER, developing DHAKA: AFTER DARK in Unity, and shipping tools for newsrooms and communities.
